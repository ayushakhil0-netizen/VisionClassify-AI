
# VisionClassify AI

### A Flask-Based Web Application for Real-Time Image Classification Using MobileNetV2

## Project Description

VisionClassify AI is a web-based image classification application developed using Python Flask and TensorFlow.

It uses the pre-trained MobileNetV2 deep learning model to identify objects in uploaded images.

## Features

- Image Upload
- Real-Time Image Classification
- MobileNetV2 Deep Learning Model
- Top 3 Predictions
- Confidence Score
- User-Friendly Web Interface

## Technologies Used

- Python
- Flask
- TensorFlow
- MobileNetV2
- NumPy
- Pillow
- HTML
- CSS
- Bootstrap

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/VisionClassify-AI.git
```

Open the folder:

```bash
cd VisionClassify-AI
```

Create virtual environment:

```bash
python -m venv venv
```

Activate environment on Windows:

```bash
venv\Scripts\activate
```

Install requirements:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

Open:

http://127.0.0.1:5000

## Model Details

Model: MobileNetV2

Dataset: ImageNet

Input Size: 224 x 224

Predictions: Top 3 Classes
